# Top Albums Finder

<img src="./img/repo-gif.gif" alt="">

**Link:** https://notare.github.io/top-albums-finder

Um site que mostra os álbuns mais ouvidos de um artista usando a API do Last.fm.

## Como Foi Feito:

**Tecnologias usadas:** HTML, CSS, JavaScript

Foi adotada uma abordagem mobile-first, garantindo que o site ofereça uma experiência fluida em diversos dispositivos. Depois de pesquisar por um artista, a página mostra os álbuns principais do mesmo, que são exibidos na página ordenados pelo número de ouvintes, mostrando a capa do álbum, o nome e um botão para mostrar a lista de faixas.

## Otimizações:

Alguns artistas possuem uma discografia extensa, o que pode levar a um excesso de rolagem para os usuários. Para resolver isso, foi introduzido um botão de "Voltar ao Topo", permitindo que os usuários retornem facilmente ao topo da página.

## Lições Aprendidas:

Uma das partes mais importantes desse projeto foi trabalhar com uma API externa e entender melhor como fazer requisições e utilizar os dados recebidos. Também trabalhei com a atualização dinâmica da página, usando essas informações para alterar o conteúdo de acordo com as ações do usuário e tornar a experiência mais interativa. Esse projeto me ajudou a entender melhor como APIs funcionam na prática e como conectar uma aplicação frontend a dados externos.
